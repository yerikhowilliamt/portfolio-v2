## Hook

This page is an implementation fixture, not a claim about a shipped client system. It demonstrates the public case-study structure with explicit boundaries.

## Problem

Free-form project content can drift into inconsistent sections, hidden evidence gaps, or unsupported claims unless the publishing contract is checked before rendering.

## Key Decisions & Trade-offs

The project uses repository-owned MDX with validated frontmatter and a fixed seven-section order. This keeps authoring close to the code and avoids a CMS, at the cost of requiring a code review and build for every content change.

```text
published content -> static route
draft content     -> excluded
invalid content   -> build failure
```
